I sit at a rare intersection: **chemical process engineering domain knowledge** combined with **custom ML pipelines in Python**. Using DWSIM, I can generate high-fidelity simulated process data — heat transfer, fluid dynamics, reaction kinetics — and feed it directly into ML models. This means I can build and validate predictive models in domains where real-world labeled data is scarce or proprietary. **It's not a workaround. It's a competitive advantage.**
